# Smart Robotic Arm Color Sorting System

## Overview
A low-cost intelligent robotic arm that detects and sorts colored blocks using OpenCV, Flask, ESP8266, PCA9685 and a 6DOF robotic arm.

<img width="1280" height="960" alt="photo_2026-05-18_20-05-13" src="https://github.com/user-attachments/assets/5ff4b9ee-6bee-4c6a-9874-d5e69368354c" />

This project presents a low-cost intelligent robotic arm capable of detecting, classifying, and sorting colored objects automatically using Computer Vision, Embedded Systems, and Web Technologies.

The system combines OpenCV, Flask, ESP8266, PCA9685, MySQL, and a 6DOF robotic arm to create a complete automated color sorting solution.

## Features
- Color detection using OpenCV
- Coordinate mapping
- Inverse Kinematics
- Real-time web dashboard
- MySQL database
- ESP8266 wireless control

## Technologies
- Python
- OpenCV
- Flask
- Socket.IO
- ESP8266
- PCA9685
- MySQL
