# Smart Robotic Arm Color Sorting System

## Overview
A low-cost intelligent robotic arm that detects and sorts colored blocks using OpenCV, Flask, ESP8266, PCA9685 and a 6DOF robotic arm.

## Features
- Color detection using OpenCV
- Coordinate mapping
- Inverse Kinematics
- Real-time web dashboard
- MySQL database
- ESP8266 wireless control

## Technologies
- Python
- OpenCV
- Flask
- Socket.IO
- ESP8266
- PCA9685
- MySQL
